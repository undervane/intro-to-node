# Intro to Node.js

This is a basic scaffolding to help you get started with a minimum boilerplate to build a node server, to bootstrap the project follow the next steps:

## 0. Previous steps

You need Node to be installed in your computer, to check it out you can run command below from console:

```
$ node -v
```

If this gives you a response like this one (don't care about the version) you are good to go:

```
v10.15.0
```
If the response says something like 'command not found', go to https://nodejs.org/en/download and install the recommended version for your platform

## 1. Start the project

1. Clone this repository:

```
$ git clone https://github.com/undervane/intro-to-node.git
```

2. Get into the project directory:

```
$ cd intro-to-node
```

3. Install dependencies with the npm package manager:

```
$ npm install
```

4. Run server:

```
$ npm start
```

You are ready to start! From your browser, go to http://localhost:3000 and you will see the response from your server.
